# Haetae: Night Gate

한국 민속 방치형 타워디펜스

Unity / C# / 모바일 (iOS · Android)

> **1차 시장** 글로벌 (북미 · 서유럽) · **소프트런치** 필리핀 · 인도네시아
> **포지션** 출퇴근길 5분으로 굴러가는, 진짜 방치되는 디펜스

**게임명은 현재 작업명입니다.**
상표 확인과 퍼블리셔 협의가 남아 있어 바뀔 수 있습니다.
그래서 코드 네임스페이스는 `IdleDefense`로 게임명과 분리해 두었습니다.
표시명이 필요하면 리소스나 설정에서 읽어오세요 — 코드에 하드코딩 금지.

**로컬라이즈** 한국·일본 출시 시 「해치: 밤의 문」

## 시작하기

```bash
git clone <repo> haetae-night-gate
```

1. Unity Hub에서 프로젝트 열기 (2D, LTS 버전)
2. `docs/Unity_에디터_작업목록.md`의 순서대로 씬 구성
3. Test Runner → EditMode → Run All

**`CLAUDE.md`가 프로젝트 규칙 파일입니다.** Claude Code가 세션마다 자동으로 읽습니다.

## 절대 규칙

코드를 건드리기 전에 `CLAUDE.md`를 읽으세요. 요약하면:

| # | 규칙 | 어기면 |
|---|---|---|
| 1 | 모든 재화·전투 수치는 `BigNumber` | 환생 10회에 정밀도가 깨져 세이브 손상 |
| 2 | 오프라인 보상은 엽전·구슬만, **도깨비불 금지** | 90일 커브 즉시 붕괴 |
| 3 | 승천은 **웨이브 + 코어 이중 조건** | 티어가 연쇄로 뚫려 콘텐츠 7일 소진 |
| 4 | 코어 일일 감쇠 하한은 **0** | 등비수렴이 깨져 무한 파밍 가능 |
| 5 | 광고 보상은 `RewardToken` 검증 필수 | 광고 없이 보상 지급 |
| 6 | 성장은 팔지 않는다 (편의·코스메틱만) | 과금이 커브를 압축 |
| 7 | 저사양·저발열이 스펙 | 차별화 자체가 사라짐 |

## 경제 설계 요약

**핵심 공식**

> 업그레이드 비용은 지수로, 파워는 선형으로 오른다.
> 그래서 언젠가 반드시 벽에 부딪힌다.

벽이 없으면 환생할 이유가 없고, 환생이 없으면 3일 만에 질립니다.

**4층 구조**

| 층 | 내용 |
|---|---|
| 1 | 웨이브 · 코인 곡선 (체력 1.09배 / 코인 1.075배) |
| 2 | 환생 메타 — 티어 승천, 웨이브+코어 이중 게이트 |
| 3 | 오방색 5트랙 곱연산 (청·적·황·백·흑) |
| 4 | 오프라인 보상 — 직전 런의 최대 30%, 광고 시 60% |

**90일 커브 (실측)**

| 플레이량 | 티어 6 도달 |
|---|---|
| 3런/일 (일반) | 89일 |
| 6런/일 (헤비) | 45일 |
| 144런/일 (자동 폭주) | 37일 |

코어 일일 감쇠로 하루 획득량이 **7.22런분에서 수렴**합니다.
1000회를 돌려도 상한이 같아 무한 파밍이 불가능합니다.

## 수치를 바꾸려면

1. `docs/방치형디펜스_경제시뮬레이션.xlsx`에서 먼저 확인
2. **환생메타 시트 O40 진단 패널이 "정상"인지** 확인
3. `EconomyConfig`의 노란 셀 대응 필드만 수정
4. `Assets/Scripts/Tests` 전체 실행

> 체력 증가율 · 티어 배수 · 도달 웨이브 지수는 서로 강하게 얽혀 있습니다.
> 하나만 바꾸면 게임이 진행 불가능해집니다. 스트레스 테스트로 확인된 사실입니다.

## 측정 후 내린 결정

방치가 아니라 계측 결과를 보고 선택한 것들입니다. 근거는 `docs/P0_계측결과_*.md`에 있습니다.

| 사안 | 결정 | 근거 |
|---|---|---|
| 승천 직후 짧은 런(1.36분) | **보정하지 않음** | 승천당 1회뿐이고 다음 런에 헤드룸 22로 자기 회복. 인위적 하한은 이 교정을 덮어씀 |
| 설계 곡선 `waveCoefficient`/`waveExponent` | **실측 재적합** (37.7→83.92, 0.269→0.1849) | 검증용 자 눈금이며 런타임 호출 0곳. 게임 밸런스 변경 아님 |
| 스프레드시트 90일 커브 | **당장 재작성 안 함** | 실측이 시트 모델보다 약 1.7배 빠름. 티어 축은 90일차 T6으로 일치하므로 주석만 남김 |
| 젬 시간당 지급 | **12 유지** (문서의 25가 낡음) | 25면 90일 잉여 25,300으로 `Validate()` 실패 (한계 5,000) |

승천 직후 건은 소프트런치에서 두 지표를 확인한 뒤 재검토합니다.
**승천 직후 세션 이탈률**과 **승천 직후 광고 시청률** — 후자가 유일하게 확인된 역전 지점입니다
(광고 시청자의 승천 직후 런이 44초로 미시청 1.36분보다 짧습니다).
