# Haetae: Night Gate — 시장 진입 및 제품 정의

**작성일** 2026년 8월 | **전제** 1인 개발 / 전업 / Unity / 모바일

---

## 1. 시장 정의 — 어디에 들어가는가

"타워디펜스"는 하나의 시장이 아닙니다. 수익 구조와 개발 난이도가 완전히 다른 세 개의 하위 시장으로 쪼개집니다. 여기를 구분하지 않으면 처음부터 이길 수 없는 싸움을 시작하게 됩니다.

### A군 — 클래식 TD (Kingdom Rush, Bloons TD 6)

- 스테이지 설계, 유닛 밸런스, 아트가 경쟁력의 전부
- 10년 이상 축적된 콘텐츠 물량으로 방어됨
- 유료 판매 또는 가벼운 IAP 모델
- **판정: 진입 불가.** 1인이 만들 수 있는 물량이 아님

### B군 — PvP 머지 TD (Random Dice, Rush Royale)

- 실시간 1대1, 3~5분 매치, 머지 + 가챠
- 시장 규모는 가장 큼 (Rush Royale 3년간 2.3억 달러 / 6,300만 다운로드)
- 서버, 매치메이킹, 안티치트, 지속적 메타 밸런싱 필수
- **판정: 진입 불가.** 인프라와 라이브 운영 인력 요구

### C군 — 방치형 싱글 TD (The Tower - Idle Tower Defense)

- 타워 1개, 웨이브 자동 방어, 영구 업그레이드
- 서버 최소한 (리더보드 정도), 대부분 로컬 계산
- 콘텐츠 물량이 아니라 **숫자 곡선**으로 굴러감
- 소규모 팀이 월 100만 달러 규모 도달을 실증
- **판정: 여기.**

> **결론: C군, 방치형 싱글 타워디펜스로 진입한다.**

## 2. 벤치마크 대상 — The Tower 해부

이 게임 하나가 사실상 우리 시장의 전부입니다. 철저히 분석해야 합니다.

| 항목 | 내용 |
|---|---|
| 개발사 | Tech Tree Games (소규모) |
| 출시 | 2021년 8월 (안드로이드) / 11월 (iOS) |
| 현재 순위 | 구글플레이 시뮬레이션 매출 9위 (2026.7) |
| 월 지표 | 다운로드 약 7만 / 매출 약 100만 달러 |
| 평점 | 4.3 |

### 구조

- 화면 중앙 타워 1개, 사방에서 적이 접근
- **워크샵** — 코인으로 영구 스탯 강화
- **연구소(랩)** — 젬으로 장시간 연구, 방치 중에도 진행
- **카드 컬렉션** — 대형 보너스 제공
- **토너먼트** — 기간제 리더보드 경쟁
- **테마/코스메틱** — 타워와 배경 꾸미기
- **이벤트** — 메달 수집 → 이벤트 상점

핵심은 **화폐가 3개(코인/젬/스톤)로 분리**되어 있고, 각각 다른 성장 축을 담당한다는 점입니다. 코인은 즉시 소비, 젬은 연구 대기시간 단축, 스톤은 장기 성장. 이 분리가 유저를 계속 붙잡아 둡니다.

### 수익 구조 (중요)

**이 게임은 광고 게임이 아닙니다.**

- 인앱 결제 $4.99 ~ $99.99
- 주간 구독 약 $14.99
- 광고 제거 상품
- 광고는 **유저 선택형 리워드만** (강제 전면광고 없음)

유저 리뷰에서 확인되는 것:
- 강제 광고가 없고 보상형 광고를 고를 수 있다는 점을 가장 좋아하는 요소로 꼽음
- 20~30달러 결제도 아깝지 않았다는 반응
- 광고 품질 문제(리워드 광고가 멈춰 보상을 못 받음)로 이탈하는 유저 존재

## 3. The Tower의 약점 — 우리의 진입 틈새

리뷰에서 반복적으로 나타나는 불만입니다. 이게 우리 제품의 설계 근거가 됩니다.

| 약점 | 유저 반응 | 우리의 기회 |
|---|---|---|
| **앱을 켜둬야 진행됨** | "방치형인데 앱을 켜놔야 한다" | 진짜 오프라인 보상 계산 |
| **배터리 소모 심함** | "배터리를 빨리 먹는다" | 경량 렌더링, 저사양 대응 |
| **후반 라운드 12시간+** | "한 판에 12시간 넘게 걸린다" | 세션 5~10분으로 고정 |
| **지수 비용 폭증** | "레벨 100까지 일주일, 성취감이 사라진다" | 완만한 초중반 곡선 |
| **초반 배속이 너무 느림** | "5배속이 필요하다" | 초반부터 배속 개방 |

> **핵심 인사이트**
> The Tower는 하드코어 인크리멘탈 유저를 위해 설계됐고, 5년간 점점 더 무거워졌습니다.
> **여기서 이탈한 캐주얼 유저층이 우리 타겟입니다.**
> 정면승부(콘텐츠 물량)로는 절대 못 이깁니다. 접근성으로만 이길 수 있습니다.

## 4. 제품 정의

### 한 줄 컨셉

**"출퇴근길 5분으로 굴러가는, 진짜 방치되는 타워디펜스"**

### 설계 원칙 4가지

1. **오프라인이 메인이다** — 앱을 꺼도 진행됨. 접속은 보상 수확과 업그레이드를 위한 것
2. **한 세션 5~10분** — 한 판이 길어지지 않게 라운드 길이에 상한
3. **저사양 우선** — 2D, 파티클 최소, 발열/배터리 관리를 스펙으로 명시
4. **초반 2시간이 전부다** — 첫 세션에서 환생(프레스티지)까지 도달시키기

### 화폐 설계 (3화폐 유지, 역할 분리)

| 화폐 | 획득 | 용도 | 성격 |
|---|---|---|---|
| 코인 | 전투 중 적 처치 | 즉시 업그레이드 | 빠른 소비 |
| 젬 | 오프라인 보상, 광고 | 연구 가속, 부활 | 중기 |
| 코어 | 환생 시에만 | 영구 배수 | 장기 |

### 초기 스코프 (프로토타입 6~8주)

**넣을 것**
- 타워 1개 + 웨이브 자동 전투
- 업그레이드 6종 (공격력/공속/사거리/체력/재생/코인획득)
- 오프라인 보상 계산
- 환생 시스템 1단계
- 리워드 광고 3곳 (오프라인 2배 / 배속 / 부활)

**넣지 말 것 (v2 이후)**
- 카드 컬렉션, 토너먼트, 이벤트, 테마, 다중 타워
- → 이걸 다 넣으려다 프로토타입을 못 끝내는 게 1인 개발 최대 실패 원인

## 5. 목표 수치

### 리텐션 (2026년 기준)

업계 상황: 중앙값 D1 약 26%. "좋다"고 할 수 있는 프로필은 **D1/D7/D30 = 35/15/5**, 상위 25%는 40/20/10.

**중요한 이점**: 방치형/AFK 타이틀은 D7·D30에서 RPG급 이상의 수치를 자주 기록합니다. 초반 D1은 화려한 장르에 밀려도, 습관화되면 오래 갑니다. 반대로 하이퍼캐주얼은 D30에 1~2%로 붕괴합니다.

| 지표 | 최소 | 목표 |
|---|---|---|
| D1 | 30% | 35% |
| D7 | 12% | 15% |
| D30 | 5% | 8% |
| 일 세션 수 | 4회 | 6회 |
| 일 플레이타임 | 10분 | 15분 |

### 수익 배분 목표

액션·전략 계열은 IAP 81.9% 대 광고 18.1% 수준입니다. 다만 우리는 더 캐주얼한 포지션이므로:

**IAP 55~60% : 리워드 광고 40~45%**

광고 전용 모델은 배제합니다. 순수 광고 모델은 현재 차트 상위에 단독 히트를 만들어내지 못하고 있습니다.
