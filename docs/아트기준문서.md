# 1. 확정 기준 — 해치 티어 1

![해치 티어 1 마스터](assets/haetae_tier1_master.png)

**파일** `assets/haetae_tier1_master.png` (1254×1254, RGBA, 투명 배경)

이 이미지가 **모든 캐릭터 아트의 기준**입니다. 티어 2~6, 도깨비, 부적 캐릭터 전부
이 톤·비례·처리 방식에서 파생됩니다.

## 1.1 확정된 이유

| 항목 | 평가 |
|---|---|
| 실루엣 | 정사각형에 꽉 참. 아이콘으로 안정적 |
| 대칭 | 좌우 대칭. 축소 시 형태 유지 |
| 정보 밀도 | 소용돌이가 갈기에만 국한 → 몸통 덩어리가 명확 |
| 표정 | 입 다문 미소. 얼굴 정보량이 적정 |
| 셀 셰이딩 | 2톤, 경계 선명 |
| 갈기 기능 | 얼굴을 감싸는 프레임 역할 → 시선이 눈으로 모임 |

## 1.2 개정 이력 — 2026-08-19 마스터 교체

**초판의 타협점이었던 '강아지에 가까운 코'가 해소됐습니다.**

초판은 코가 작고 둥근 남색이라 해치보다 강아지로 읽혔고, 당시에는
"수정 시 다른 요소가 무너질 위험"을 이유로 재론하지 않기로 했습니다.

실제로 해보니 무너지지 않았습니다. **넓은 주황 타원 코**로 바꾸면서
사자 계열 얼굴 구조가 살아났고, 여기에 **어깨 날개**를 더해
중국 사자상과도 확실히 구분됩니다.

| 항목 | 초판 | 현행 |
|---|---|---|
| 코 | 작고 둥근 남색 | **넓은 주황 타원** |
| 입 | 다문 미소 | **벌린 미소 + 송곳니 2개** |
| 어깨 날개 | 없음 | **있음** |
| 소용돌이 | 갈기에만 | **갈기 + 배 중앙 1개** |

> **교훈** — "재론하지 않는다"는 판단은 근거가 바뀌면 뒤집어도 됩니다.
> 다만 뒤집을 때는 문서를 같이 고쳐야 합니다. 문서와 실물이 갈라지면
> 이후 아트가 어느 쪽을 따를지 알 수 없게 됩니다.

# 2. 축소 검증 결과

스토어 아이콘이 CPI를 좌우하는 시장이므로 **모든 캐릭터는 축소 테스트를 통과해야 합니다.**

| 크기 | 이미지 | 판정 |
|---|---|---|
| 128px | ![128](assets/haetae_tier1_icon128.png) | **통과** — 뿔·눈·갈기 프레임 모두 식별 가능 |
| 48px | ![48](assets/haetae_tier1_icon48.png) | **통과** — 형태 덩어리와 노란 뿔 포인트 유지 |

**검증 방법**

```
새 에셋 → 128px로 축소 → 뭉개지면 디테일을 덜어낼 것
```

48px에서도 **노란 뿔이 시각적 앵커**로 작동합니다.
티어가 올라가도 이 포인트 컬러는 유지하세요.

# 4. 스타일 규칙

## 4.1 필수 프롬프트 블록

새 캐릭터를 생성할 때 **반드시 그대로 사용**하세요.

```
Flat vector illustration with cel shading.
Exactly TWO tones per color: one base flat color and one
darker shadow color, with HARD sharp edges between them.
NO gradients, NO soft blending, NO airbrush, NO texture.
Shadow placed consistently on the lower-left.
Bold clean outlines in dark navy (not black).
Sticker style, transparent background.
```

> `HARD sharp edges`와 대문자 `NO`가 핵심입니다.
> 이것이 없으면 모델이 부드럽게 번지게 만듭니다.

## 4.2 캐릭터 고정 요소

티어 2~6 및 파생 캐릭터에서 **절대 바뀌면 안 되는 것들**입니다.

| 요소 | 규칙 |
|---|---|
| 몸통색 | 옥색 (`#57B398`) |
| 크림 부위 | 배 · 발 · 눈썹 구름무늬 |
| 뿔 | 노란색. 크기만 변화 |
| **코** | **넓은 주황 타원.** 세로보다 가로가 길다 |
| **소용돌이 문양** | **갈기 + 배 중앙에 큰 것 하나.** 다리 · 꼬리는 단색 |
| **어깨 날개** | **작은 날개깃 한 쌍.** 어깨·겨드랑이 위치. 크림색 |
| 자세 | 앉은 자세, 정면, 좌우 대칭 |
| **입** | **벌린 미소 + 위 송곳니 2개.** 혀는 노출 금지 |
| 음영 방향 | 좌측 하단 고정 |

**배의 소용돌이는 '큰 것 하나'입니다.** 초판이 소용돌이를 갈기로 제한했던
이유는 128px에서 몸통 덩어리가 뭉개지는 것을 막기 위해서였습니다.
큰 형태 하나는 그 문제를 일으키지 않지만, **잔무늬를 여러 개 넣으면
초판이 우려한 그대로 됩니다.** 다리와 꼬리는 계속 단색입니다.

### 어깨 날개를 추가한 이유 (2026-08-19)

전통 해치 도상에는 어깨·겨드랑이에 **작은 날개깃**이 있습니다.
중국 사자상(狛犬)에는 없는 요소라, **한국 해치임을 한 눈에 알리는
가장 값싼 표식**입니다.

글로벌 1차 시장에서 중국풍으로 오독되는 것이 이 프로젝트의 반복된
위험이므로(6.1절의 한자 사건 참조), 색·비례를 건드리지 않고 정체성을
더할 수 있는 이 요소를 고정 요소에 넣습니다.

**작게 유지하세요.** 크면 실루엣이 무너지고 아이콘 여백을 낭비합니다.
접힌 상태로 몸통에 붙은 정도면 충분합니다.

## 4.3 금지 사항

- 그라데이션, 텍스처, 소프트 라이팅
- 몸통 · 다리 · 꼬리의 장식 문양
- **서울시 마스코트 '해치'의 디자인 차용** — 지자체 공식 상징물입니다.
  실루엣 · 노란 몸통 · 벌린 입과 송곳니를 따라가면 상표 문제이고,
  게임이 지자체 홍보앱으로 읽힙니다. 전통 도상은 참고하되 그 마스코트는
  참고 대상이 아닙니다.
- **노란색 몸통** — 티어 6이 황금 해치입니다. 티어 1을 노랑으로 시작하면
  6단계 성장의 마지막 카드가 사라집니다. 옥색 → 황금이 곧 성장 서사입니다.
- 꼬리가 바깥으로 크게 뻗는 실루엣 (아이콘 여백 낭비)
- 위압적 · 사나운 표정 (원형이 사자상이라 방치하면 그렇게 나옴)
- 순수 검정 외곽선

## 5.2 단순화 요구

> **위 두 이미지는 톤 참고용이며, 그대로 쓸 수 없습니다.**

현재 그라데이션과 텍스처가 과다합니다. 저사양 · 저발열이 본 프로젝트의

**요구사항**

- 레이어 **3~4개**로 단순화 (하늘 / 원경 산 / 중경 / 근경)
- 각 레이어는 **단색 또는 2톤**
- 그라데이션 제거
- 패럴랙스 스크롤을 전제로 레이어 분리 저장

# 7. 티어 2~6 생성 가이드

## 7.1 일관성 확보 방법

**두 가지를 병행하세요.**

1. `haetae_tier1_master.png`를 **레퍼런스 이미지로 첨부**
2. 4.2절의 고정 요소를 **프롬프트에 명시**

둘 중 하나만으로는 흔들립니다.

## 7.2 단계별 변주

**공통 지시** (매번 포함)

```
Same character as reference: jade green body #57B398,
cream #FCF0CF belly / paws / eyebrow swirls,
ONE yellow horn #FDCD4F,
BROAD ORANGE OVAL NOSE, wider than tall,
open smiling mouth with TWO small upper fangs (no tongue),
a small pair of folded cream wings at the shoulders,
decorative swirls on the mane AND one large swirl on the belly
  — legs and tail stay flat single color,
sitting upright, symmetrical, shadow on lower-left.
```

| 티어 | 변주 지시 |
|---|---|
| 1 | 확정 완료 |
| 2 | `Horn grown taller and sharper. Slightly larger body. Alert upright posture.` |
| 3 | `Small orange flame from mouth. Mane slightly fuller. Standing on four legs.` |
| 4 | `Full flame-shaped mane as flat layered shapes. Larger, more dignified.` |
| 5 | `Two haetae mirrored side by side. One jade green, one deep indigo.` |
| 6 | `Entire body in flat gold and ochre. Glowing horn. Majestic but still rounded.` |

## 7.3 검증 절차

각 티어 생성 후:

- [ ] 티어 1과 나란히 놓고 **같은 캐릭터로 보이는가**
- [ ] 128px 축소 후 형태가 읽히는가
- [ ] 음영이 좌측 하단인가
- [ ] 소용돌이가 갈기에만 있는가
- [ ] 노란 뿔 포인트가 유지되는가

# 8. 새끼 해치의 확장 사용

> **티어 1 해치를 티어 1에서만 쓰는 것은 낭비입니다.**
> 유저는 곧 뿔 버전 · 갈기 버전으로 넘어가버립니다.

**새끼 해치를 UI 상시 마스코트로 사용하세요.**

| 위치 | 용도 |
|---|---|
| 오프라인 보상 화면 | 보상 안내 |
| 로딩 화면 | 대기 중 |
| 튜토리얼 | 안내 |
| 광고 제안 팝업 | "도깨비를 한 번 더 부를까?" |
| 스토어 아이콘 | 브랜드 |
| 빈 상태 · 오류 | 안내 |

**필요 작업** — 표정 변주 4~6종만 추가하면 됩니다.
기쁨 / 놀람 / 졸림 / 응원 / 곤란 / 윙크.
몸은 그대로 두고 얼굴만 교체하는 구조로 만드세요.

이러면 **티어와 무관하게 게임의 얼굴로 남습니다.**
